# Contributing to Research Relay

Thanks for testing Research Relay.

## Useful contributions

The most useful reports include a concrete Task Packet, what happened, what you expected, and whether the failure came from the Dispatcher, Worker, evidence policy, or result intake.

Good contribution areas include:

- smaller or clearer Task Packet schemas;
- evidence-policy edge cases;
- failure and conflict handling;
- examples from real long-running projects;
- pressure tests that expose context leakage;
- documentation improvements.

## Issues

Use an Issue for a reproducible bug, protocol problem, or concrete feature request.

## Discussions

Use Discussions for workflow ideas, questions, examples, and broader design proposals.

## Pull requests

Keep changes focused. For protocol changes, explain the failure mode being solved and include at least one before/after example or pressure test.
